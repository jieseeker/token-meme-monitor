# A 观察、B 首次启动、C 二次启动：设计草案

日期：2026-10-24。状态：用户已授权由代理完成设计取舍、开发测试、回放验证、提交推送及云端发布，用户负责结果验收。常规实现决定不再逐项确认。

源码基线：`main`，`35f699a1e1430a9e3a7c5746d90ea8cf0c2c3225`。写稿前仅有未跟踪的 `signal-v2-feasibility-review.md`。

本稿继承[可行性评估](../../../signal-v2-feasibility-review.md)的数据限制、影子隔离、风险顺序和七天清理要求。后台刷新沿用 `openspec/changes/background-task-chain-optimization/`，不复制或改写其任务策略。

## 已确认的产品选择

- 面板帮助使用者发现、研究和跟踪机会；交易由使用者在外部交易所完成。
- **A 为观察名单**：尽早收录异常候选，接受部分候选没有后续行情。
- **B 为主信号**：识别首次放量与价格结构突破，记录当时可见的证据。
- **C 为后续二段机会**：B 后先有首波推进，再有回调、企稳，最后突破回调整理区间上沿。
- C 不要求重新突破首波高点；必须展示它与首波采样高点的位置关系。
- 上述 A/B/C 是产品阶段名称，不是原 V2 规格中的两条“量价路径 A / OI 路径 B”。文档与未来字段应明确使用 `watch`、`first_start`、`second_start`，避免混用。

目标是增加有证据的提前关注机会。不会把“提前数小时”“误报更低”或四个案例的涨幅当成已经验证的效果。

## 方案选择

讨论过仅做 A 提前观察、以 B 启动初期为主、仅做 C 突破确认三种产品方向。用户选择组合：A 观察、B 主信号，并将 C 明确为回调后的第二次启动，而非 B 后多等待几分钟。

C 的两种触发方式也已比较：

| 方式 | 取舍 | 决定 |
| --- | --- | --- |
| 突破回调整理区间上沿 | 更早，但可能只是下跌过程中的反弹 | 用户选择 |
| 重新突破首波高点 | 条件更明确，但通常更晚 | 不作为 C 的必要条件 |

实现方式由本稿建议：同一条现有采集流、同一 token 事件逐阶段推进；旧活跃分仍是背景和对照。阶段不能独立加分后相加，也不能为 A/B/C 各开一套外部请求。先验证量价 A/B，随后验证同一事件内的 C；OI 在身份与时间可靠后作为可选证据接入。

## 数据边界与首版范围

1. 首版复用 DexScreener 池级快照。一个事件冻结一个明确的参考池；仅在现有 `selected_pools` 选中且会持久化的池中，选择初次有效观测中流动性最高且有有效价格的池，相同流动性按池地址确定顺序。后续不能随权重、DEX 返回排序或池集合改变参考价格。冻结池后续未进入现有选中集合时，即使完整响应中仍有它，也按本次未观测处理；首版不扩大旧快照集合或额外请求，必须量测由现有前三池限制导致的中断。
2. 固定参考池是设计者提出的首版工程取舍，不改变现有页面的合并展示价。事件明确标注参考池和覆盖范围，不能称为全网资金确认。参考池缺失时暂停，超出断档容忍范围后结束结构观察；不得无缝换池续接。
3. `observed_at` 只代表本机抓取时间。保存字段存在性、独立请求标识、请求完成时间和来源时间状态；不把缺失字段写成 V2 的零。首版建议复用新快照已有的 `raw_json` 列保存这份小型元数据，不保存完整响应或另复制行情；旧 `raw_json={}` 的快照不追认字段有效，也不用于 V2 基线，因此会有真实的基线预热期。
4. 本地缓存重读、同一次响应的多个池写入、相同观测重复消费都不能推进阶段。完全相同的相关行情内容不增加“新证据次数”。独立请求即便内容变化，也不能证明 DexScreener 上游刚刚更新，须保留 `source_time_unverified`；首版只能形成“采样结构命中”的影子结论。
5. `volume_h1/m5` 是滚动值，不相加重建 K 线成交额，不据此宣称精确吸筹、净流入或回调段累计成交。买卖笔数不解释成主动买入金额。
6. 小时 OI 不能确认分钟级企稳。同名 ticker 不足以证明资产相同，未验证映射的 OI 不参与判断；缺 OI 不影响完整的量价判断。
7. 首版不扩监控市场、不建长期库、不回补日周线、不新增钱包归因或通知平台。四币是否在当前 BSC Alpha 覆盖内、异动先发生在哪个市场，必须作为覆盖诊断单独记录。

## 事件与阶段

每个 `(chain, token_address)` 同时只有一个活动事件；多个池、多个候选入口不能重复建立同一事件。事件从建立日起最多存在七天，不能靠更新存活时间延长。

| 阶段 | 所需事实 | 输出含义 |
| --- | --- | --- |
| A：观察 | 同口径成交异常，或旧活跃分首次进入关注区；后期可加可靠 OI 异常入口 | 候选，尚未证明启动 |
| B：首次启动 | 首次越过过去采样区间上沿时冻结该上沿、参考样本与突破时间；成交相对背景增强且绝对量达标，后续新观测维持 | 首次启动的采样证据成立 |
| 首波推进 | B 之后的新价格进一步上涨，产生足够的已观测推进幅度 | 允许开始寻找二段结构 |
| 回调 | 相对首波已观测高点发生足够回落，且没有达到结构失效条件 | 开始记录回调，不能称为企稳 |
| 整理观察 | 回调后出现有时长、有覆盖的新观测区间，价格波动收窄且未继续明显创新低 | 有一个可供再突破的参考区间 |
| C：二次启动 | 突破已冻结的整理上沿、成交重新增强，且后续新观测仍在上沿以上 | 二段启动的采样证据成立 |

A 可以来自不同入口，但 B 必须独立满足其确认条件；旧高分不等于 B。A 可以长期停留或过期；B 可以失效而没有 C。首次运行、重启或首次看见某币时，不根据当前高价直接补出历史 B/C。

首次看见 token 且某候选入口已达标，可以建立“首次观察到的 A”，不得倒推异常起点。活动事件内重复入口归并；当前事件终止后，同一入口必须先有一次新的有效观测回到未命中，再由未命中转为命中才允许新建事件，其他已复位的入口可独立重新触发。每个入口只保存最后判定和是否复位，不存无限历史；状态与事件一起落库，重启不视作首次看见。该有界状态同样在事件最初建立七天后删除；删除后按新观察周期处理，允许新的 A，但仍须重新经历之后的新突破与完整观测才可 B/C，不能补出旧行情。

阶段、数据状态、风险状态分开存储。数据过期显示“最后阶段 B，当前数据过期”，不将请求失败直接解释为市场结构失效，也不继续作为当前有效机会。

## C 的时间顺序与冻结规则

1. B 成立时记录 B 时间、价格及 B 前参考上沿。首波推进仅使用 B 后新观测，不能拿 B 前已经发生的涨幅凑条件。
2. 首波高点只表示当时已采到的高点。达到回调条件前可随新高更新；进入回调后冻结该首波高点，以它计算回撤与“距离首波高点”。
3. 先出现回调，再开始收集整理区间。回调门槛首次满足时，以该次观测为窗口起点并固定其价格为候选低点参照；后续价格若低于此参照的 0.5% 容忍线，就从该次新观测重新开始窗口并固定新的参照。窗口波幅超过 3% 但尚未达到结构失效时，同样只从当前新观测重开，不回头挑选最优区间。首版采用**第一个同时满足价格时长、覆盖、窄幅、低点约束及 m5 成交基线完整性的窗口**；该窗口完成后冻结上沿、下沿及基准成交观测。当前突破样本不得纳入参考窗口。
4. m5 基线不足时窗口继续向前收集，不能先冻结成一个永远缺基线的窗口；形成后至少等一个后续样本才能尝试 C。冻结前的重开只能使用当时已见观测，不能在看见未来反弹后挑选过去最低点并回填企稳时间。冻结后不随上涨抬高上沿，也不随下跌下移下沿；未形成整理就越过冻结首波高点时，取消本轮 C 观察，记为首波延续，不能补造整理过程。
5. C 只在冻结之后的新观测突破时开始确认。首版使用同一参考池的有效 m5 滚动成交，与整理期至少三个相隔五分钟的 m5 观测中位数比较；这只是近期滚动成交重新增强，不称为回调段真实缩量。当前 m5 缺失、基线不足或有断档时，C 为待核查；不使用仍包含首波的 h1 高成交替代。
6. 突破后至少再有一个合格的新观测维持在上沿以上，才能记录 C。记录的是此时的确认时间，不倒写到回调低点或最早突破时间。
7. 一个 B 事件首版最多产生一次 C。确认前跌破冻结整理下沿、首次结构支撑失效、来源变化或窗口到期，则结束本次 C 观察；不得持续降低上沿以强行触发。以后是否重新建轮次另行评估，首版不做无限多段。

## 影子试验初值（设计者建议，未做效果校准）

这些初值只用于让试验可复现。实现计划可根据采样覆盖分布修正并记录原因；改动参数必须变更试验版本，不能在同一对照结果中混算。

| 项目 | 初值与限制 |
| --- | --- |
| 成交背景 | 判断时刻 t，取 `[t-24h, t-1h]` 内有效 h1 观测，按 UTC 小时桶各取最后一条；至少 12 桶，最早不晚于 `t-20h`、最晚不早于 `t-3h`，最大内部缺口不超过 2 小时；所有样本结束时刻不晚于 `t-1h`，与当前滚动小时不重叠 |
| A 成交入口 | 当前 h1 至少为可比历史中位数的 1.5 倍，且达到现有 `min_volume_h1_usd`；旧分首次达标保留为另一个候选入口 |
| B 成交条件 | 当前 h1 至少为同基线的 2 倍，且达到现有绝对量门槛；三种成交指标仍只是一类证据 |
| B 价格参考 | 过去一小时采样高点，至少覆盖四个不同五分钟桶、最早与最晚至少相隔 45 分钟；基线缺失则不确认 |
| B 维持 | 首次越过参考上沿 0.5% 后，再有两次合格新观测，首次至末次至少 4 分钟、最多 15 分钟，任意相邻间隔不超过 5 分钟；末次仍在突破线上，期间未跌回参考上沿以下 |
| B 已延伸 | 确认时超过冻结突破线 8%，只记已延伸，不冒充刚启动 |
| C 激活首波 | B 后已观测涨幅至少 8%；低于该值不寻找二段 |
| C 回调 | 从冻结首波采样高点至少回落 2%，且回吐 B 后首波涨幅的 20%～60%；超过上限视为本轮结构失效 |
| C 整理 | 至少 10 分钟，至少三次合格价格观测；相邻价格观测间隔不超过 5 分钟，采样高低幅度不超过 3%；后续样本不得跌破窗口首样本价格的 0.5% 容忍线，同时具有三条相隔至少五分钟的有效 m5 基线。以四分钟节奏采样时，可能需收集到第 16 分钟，不能将 10 分钟误当作固定完成时刻 |
| C 再启动 | 新价越过冻结整理上沿 0.5%；有效 m5 成交至少为整理期上述基线的 1.5 倍，且达到现有 `min_volume_h1_usd × 0.12`；至少一个后续观测仍在线上，间隔至少 60 秒、至多 5 分钟 |
| 结构支撑 | B 前冻结参考上沿为首版支撑；两次合格新观测低于它的 0.5% 容忍线，则本轮 B/C 结构失效；整理冻结后一次合格观测跌破整理下沿 0.5%，取消本次 C 观察 |
| C 已延伸 / 到期 | C 确认时距其冻结突破线超过 8%，记已延伸；B 后 24 小时仍未 C 则结束 C 观察；事件历史仍按七天清理 |

当前刷新资格阈值为 120/240/900 秒，且受排队影响。五分钟连续性要求会使部分冷门币不能形成 B/C，这是需要量测的采样覆盖损失；不通过把旧缓存算新样本或放宽成十五分钟无条件连续来掩盖。此阶段不改变原调度，因此也不承诺精确分钟级形态。

连续性统一按最后一次**被接受且去重后的有效新观测的抓取时间**计算，不按最后一次成功但内容重复的请求续期。B 待确认期间超过五分钟则取消此次突破确认，只有价格再次回落至冻结突破线或以下，随后出现新的越线，才开启新的 B 尝试。B 已成立后，从首波推进到 C 确认任一阶段发生超五分钟断档，均结束该 B 的本轮 C 资格，保留最后阶段并标注数据中断，恢复后不得继续接上原首波或补发 C。该限制也会排除长时间行情内容不变、无法证明有新证据的结构，必须与请求失败分别统计。恢复和重启都应用这套规则；A 可继续观察，但重新建立事件须遵守入口复位规则。

## 风险与缺失

沿用评估中的 `BLOCK > HOLD > WARN > PASS`，所有可比风险收齐后再计算当前结论资格。市场结构事实可以记录，但关键数据缺失、源状态不明或明确阻断不能被成交高分抵消。

首版量价结构、来源时间状态和风险分别输出。所有首版 DexScreener 结构命中都保留上游时间未验证标记，不能展示为已验证的实时市场确认。正式用户可见的 B/C 资格在后续对外切换评估中单独决定，本稿只批准设计范围。

FDV/流动性保护不因想命中更多币而直接删除；链上小池的风险也不能被描述成已验证的交易所风险。美元流动性下降仅作可比风险事实，不能直接断言撤 LP。深度与大额交易暂作补充背景，不作为每个候选都必须等待的采集链；未覆盖的检查明确标注未检查。

## 最小实现边界与兼容

- 复用 worker 同一响应，构建保留缺失状态的 V2 输入；采用一个小的纯判断模块、显式时钟及有界事件状态。不要为了 V2 大规模拆 dashboard。
- 独立保存当前事件与重要变化摘要，不写旧 `signals`、不修改旧列表和分数、不改变旧刷新优先级；shadow 不发通知，也不新增通知发送器。
- 只对阶段、风险或有效性变化写摘要，不按每池、每次轮询重复写完整结论。新增状态按初始事件时间清理，摘要按记录时间清理，均最多七天。
- 状态保存参考来源、最后消费观测、阶段参考价格与时间即可；不得为 C 复制一份全量快照历史。所需基线读取限制在单参考池和短窗口，复用其索引；不得每轮对全库逐 token 扫七天。
- 重启恢复已有事件并校验最新观测与连续性。出现来源变更、过期或写入中断时不能自动追认断档阶段。
- 旧分仍按现有方式提供活跃度与调度。V2 和旧规则在同一采集输入上比较，后续如需改变刷新策略，作为独立试验，避免把采样改善误认成规则改善。
- 后续页面只读取后端结论，不能在浏览器重新推导阶段。具体布局属于后续页面设计；本稿不新增卡片或改图表。

## 实施顺序与验收

1. P0：记录四币覆盖与参考市场限制；补 V2 字段存在性、观测身份、时间状态、固定来源及影子隔离检查。旧风险修复如涉及外部行为，独立变更与回归。
2. P1：A/B 同输入影子试验，记录有资格判断比例、基线不足率、首次候选到确认的实际延迟，以及高分/低分币覆盖差异。
3. P2：复用 B 事件推进 C，验证首波、回调、整理、再突破的严格先后与一轮一次；按当前来源标成采样结构命中。
4. P3：在可验证资产映射后比较“量价”和“量价加小时 OI”。未验证 OI 不参与；不因本次任务引入新采集服务。
5. 只有在输入可靠性、容量和影子结果经审阅后，才单独考虑页面展示、调度提速或正式结论切换。

适用的最小检查：重复缓存与同一响应不得推进；缺失不当零；参考池/集合变化不得造突破；B 前涨幅不能激活 C；没有首波或没有回调不得 C；整理形成前不得冻结可被未来选择的底部；当前突破不得加入历史上沿；持续上涨不能重复 C；h1 首波成交不能替代 C 的 m5 重启证据；断档恢复不回填；已延伸与结构失效分开；重启不重复事件；七天清理及旧查询/旧优先级不受影子写入影响。

量测候选与确认数量、覆盖率、延迟、回撤和未启动案例；设置相同研究/提醒数量预算，与旧规则在同一输入上比较。按当时可获得的数据评价，不用未来峰底倒填触发时间；仅四个上涨样本和七天观察都不能证明稳定有效。

影子不开启则没有额外对外行为。回滚关闭 shadow，旧表、旧查询、旧调度继续运行，新数据按七天规则清理。额外 SQLite 写锁、磁盘或 worker 延迟超预算时停止影子，保留诊断，不在生产库执行试验性迁移或压缩。
